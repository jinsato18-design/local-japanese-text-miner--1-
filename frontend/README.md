# 日本語アンケート・テキストマイニングツール (Local Japanese Text Miner)

ブラウザ内完結・完全オフラインで動作する日本語アンケート自由記述欄特化型のテキストマイニングツールです。  
1,000件〜10,000件規模（1データあたり最大1,000字程度）のテキストデータを、外部サーバーと一切通信することなくローカル環境（クライアント端末のメモリ内）のみで高速に形態素分割・頻度集計・共起分析・感情判定を行います。

---

## 主な特徴

1. **外部通信ゼロ・完全オフライン実行（高セキュリティ）**
   - 顧客アンケート、社内従業員意識調査、個人情報・機密情報を含む自由記述テキストも、外部APIやクラウドに一切送信されません。
   - インターネット遮断環境（閉域網・オンプレミス端末・オフラインPC）でも動作します。

2. **1,000〜10,000件規模のデータを快適に解析**
   - 最新のWeb標準API（`Intl.Segmenter`）およびUIブロッキングを防ぐチャンクバッチ処理を採用。
   - 1データ最大1,000字程度の長文記述でもブラウザが固まることなくスムーズに処理します。

3. **一般的なテキストマイニングツールの必須機能を網羅**
   - **単語頻度集計 (TF/DF)**: 名詞・動詞・形容詞の出現回数および出現文書率、極性スコアの算出。
   - **インタラクティブ・ワードクラウド**: 感情（ポジティブ／ネガティブ）または品詞に応じたカラーマッピング、クリックによるドリルダウン。
   - **共起ネットワーク (Co-occurrence Network)**: Jaccard係数に基づく関連語グラフ。力学モデルによる自動レイアウト、ノードドラッグ、閾値調整対応。
   - **2-gram (バイグラム) 連語抽出**: 頻出する複合語・係り受けフレーズの自動抽出。
   - **感情・満足度分析 (Sentiment Analysis)**: ポジティブ／ニュートラル／ネガティブ自動判定、属性・セグメント別クロス集計。
   - **KWIC・原文ブラウザ (Key Word In Context)**: 単語クリックやキーワード検索による前後文脈のハイライト表示、条件付きCSVエクスポート。

## 画面・機能一覧

| タブ | 機能概要 |
| :--- | :--- |
| **ダッシュボード概要** | 全体の総回答数、抽出単語数、平均文字数、ポジティブ率、最頻出Top10グラフ、ワードクラウド簡易プレビュー。 |
| **単語頻度ランキング** | 出現頻度(TF)、出現文書数(DF)、文書カバー率、極性スコアの一覧テーブル。任意の単語から原文へジャンプ可能。 |
| **ワードクラウド** | 視覚的な単語出現頻度マップ。文字サイズが頻度を、色が感情傾向（緑:好意、赤:不満、灰:中立）を表します。 |
| **共起ネットワーク** | 同一回答内で同時に使われやすい単語の関連図。話題のクラスタや文脈構造を可視化します。 |
| **2-gram 連語フレーズ** | 「使いやすい」「サポート 対応」など、連続して使用される語句パターンを自動抽出。 |
| **感情・満足度分析** | ポジネガ円グラフ、および属性（年代・プラン等）別の不満・満足比較クロスチャート。 |
| **KWIC・原文ブラウザ** | キーワードや感情・属性で絞り込み、文脈を確認できる原文ビューア。絞り込み結果のCSVダウンロード対応。 |

## 動作要件

- **対応ブラウザ**: 
  - Google Chrome (最新版推奨)
  - Microsoft Edge (最新版推奨)
  - Mozilla Firefox (最新版推奨)
  - Apple Safari (最新版推奨)
- **メモリ**: 4GB以上のRAM（10,000件処理時は8GB以上推奨）

## CSVファイルの取り込みフォーマット

本ツールはカンマ区切り（`.csv`）およびタブ区切り（`.tsv`）ファイルに対応しています。  
ファイル1行目はヘッダー行として扱われます。

### 推奨列構成

```csv
回答テキスト,属性カテゴリ,満足度スコア
"UIが直感的で使いやすく、サポートの対応も早かったです。","30代 / プレミアムプラン",5
"混雑時間帯に読み込みが遅くなりエラーが出ます。改善を希望します。","40代 / スタンダード",2
"機能としては十分ですが、設定画面が複雑で分かりづらいです。","20代以下 / 無料プラン",3
```

- **第1列（必須）**: 自由記述アンケートの回答本文（最大1,000文字程度）
- **第2列（任意）**: 属性・セグメント情報（性別・年代・契約プラン・担当拠点など）
- **第3列（任意）**: 満足度などの数値評価（1〜5点など）

※ 最低限「第1列（回答本文）」さえあれば解析可能です。

## 使い方・操作手順

1. **初期状態（デモデータ）**
   - 起動直後に約1,200件の日本語アンケートサンプルデータが自動生成・解析され、各種グラフやネットワークが表示されます。
2. **手持ちのCSVを解析する**
   - 画面右上の「**CSVファイルを読込**」ボタンをクリックし、手元のアンケートCSVファイルを選択します。
3. **フィルタとノイズ除去**
   - 画面上部のフィルタバーで「抽出品詞（名詞・形容詞・動詞）」の切り替え、「最小出現回数」の変更が可能です。
   - 社名など分析ノイズになる単語は「除外語（カンマ区切り）」に入力すると即座に除外されます。
4. **キーワードから原文へのドリルダウン**
   - ワードクラウド、共起ネットワーク、単語ランキング表の単語をクリックすると、即座に「**KWIC・原文ブラウザ**」に切り替わり、該当する回答文の前後の文脈を確認できます。
5. **分析結果の出力**
   - KWIC原文ブラウザの右上「現在の絞り込みをCSV出力」から、感情判定フラグや文字数を付与したデータをCSVファイルとしてダウンロードできます。

## プライバシーとセキュリティについて

本ツールには、外部へのデータ送信、トラッキング、外部AI APIの呼び出しコードは含まれていません。  
すべての日本語テキスト処理・形態素解析・グラフ描画は、お使いの端末（ブラウザのJavaScript実行エンジン）上だけで行われます。ブラウザを閉じるとメモリ上のデータは消去されます。
